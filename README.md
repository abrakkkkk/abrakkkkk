- Integração bidirecional com a API do **Discogs** para enriquecimento de metadados.
- Scanner mobile para código de barras, sistema de reposição de itens e relatórios de movimentações.

> `Next.js 16` · `React 19` · `Supabase` · `Vitest` · `Playwright`
